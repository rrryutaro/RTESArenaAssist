状态界面样式（角色表）

此功能会以你选择的样式（角色表）在状态标签页中显示状态。请用状态标签页顶部的“视图”选择样式。翻译标签页中的状态界面和属性分配（角色创建与升级）也使用同一种样式。

样式是一个HTML文件（模板）。你可以选用内置样式，也可以自己制作。除了属性及其修正值，角色表还可以显示角色的状态、各身体部位的护甲等级，以及面孔和全身像。

这是Assist的显示功能。它与游戏自身的状态界面（官方手册中称为“角色表”）是分开的，游戏的界面不会改变。

切换视图

用状态标签页顶部的“视图”，选择“标准”（此前使用的显示）或某一种角色表样式。你的选择会保留到下次启动。

  • 翻译标签页中的状态界面和属性分配会使用这里选择的视图。翻译标签页没有自己的选择器。
  • 数值是Assist从游戏中读取的值，与“标准”视图相同。角色表只负责显示，绝不会更改游戏中的数值（通过作弊设置更改数值要在“标准”视图中进行）。
  • 只有在Assist已连接游戏且正在显示状态时，才会显示角色表。

你自己的角色表

存放位置

点击状态标签页上的“打开文件夹”，即可打开存放你自己的角色表的文件夹。

  • 该文件夹是 character_sheets，与RTESArenaAssist.exe位于同一位置。
  • 首次打开时，Assist会创建该文件夹，并把内置样式的副本放入其中（不会覆盖已有文件）。最简单的入手方式是编辑一份副本。
  • 文件夹中的每个 .html 文件都会出现在“视图”列表中。它的名称是文件的 <title> 文字（没有则用文件名），后面加上“（文件夹）”。修改 <title> 即可重命名。
  • 编辑文件后，请点击状态标签页上的“重新加载”。
  • 请将文件保存为UTF-8。

支持的 HTML

角色表使用Qt的简易HTML显示，而不是浏览器（不使用互联网连接）。

  • 支持：表格（table）、文字的颜色、大小、粗细和字体、背景色、边框（border、border-collapse）、间距（padding、margin）、图片（img）、<style> 块中的类等。详情请参阅Qt文档中的“Supported HTML Subset”。
  • 不支持：脚本、flex 和 grid、重叠（position）、圆角等。请用表格来构建布局。
  • 同一文件夹中的图片和样式表可以用相对路径使用（例如 <img src="bg.png">）。文件夹之外的文件和互联网上的文件不会被读取。链接不会被打开。
  • 宽度为100% 的表格，在每一列都以 % 指定宽度时更能保持形状。

语法

在HTML中写入以下内容，该位置就会插入对应的值。

语法含义
{{key}}一个值（见“数值”）。在尚无法读取该值时显示“—”
{{label.key}}一个标签（见“标签”），以显示语言呈现
{{img.face}} / {{img.body}}面孔或全身像（见“图片”）。请按 <img src="{{img.face}}"> 的形式使用
{{#if key}} … {{else}} … {{/if}}仅当key的值可以读取（不为空）时显示前一部分，否则显示 {{else}} 之后的部分。{{else}} 可以省略。代码块可以嵌套。0 算作可以读取的值
  • 未知的key会显示为 [key?]，以便轻松发现拼写错误（例如 {{golf}} 会变成 [golf?]）。不匹配的 {{else}} 或 {{/if}} 会显示为 [else?] 或 [/if?]，未闭合的 {{#if}} 会在文档末尾加上 [/if?]。
  • 大括号内允许有空格，例如 {{ key }}。
  • HTML注释（<!-- … -->）内不会插入任何内容。每个内置样式顶部的注释中列出了各个key。
  • 值会以对HTML安全的形式插入（值中的 < 或 & 会按原字符显示）。

药水数量

在游戏的装备列表中，为每种想要显示的药水勾选“角色表”列。游戏中已鉴定的15种药水都可以选择。治疗、恢复疲劳和治疗疾病为初始选中项。

Key内容示例
potion_1_name … potion_15_name以显示语言呈现的所选药水名称治疗药水
potion_1_short … potion_15_short以显示语言呈现的所选药水简称（省略固定的“药水”字样）治疗
potion_1_compact … potion_15_compact紧凑卡片用的名称（简称超过14个字符时用省略号截断）治疗
potion_1_count … potion_15_count对应药水的持有总数4
  • 编号按药水种类被选中的先后顺序排列。未使用的槽位没有值。
  • 内置的“属性卡片（深色）”样式使用大卡片，只显示最先选中的六种。自定义的HTML样式可以使用全部15种的key。
  • 未鉴定的药水因种类未知而无法选择。无法读取物品栏时，这些值也不存在。

魔法装备的效果与使用次数

在游戏的装备列表中，为每件想要显示的魔法装备勾选“角色表”列。已鉴定且剩余使用次数可读取的物品可以选择。同名的实体物品会分开显示。

Key内容示例
magic_item_1_name … magic_item_40_name以显示语言呈现的所选魔法装备名称物品名称
magic_item_1_effect … magic_item_40_effect以显示语言呈现的魔法效果名称魔法效果
magic_item_1_uses … magic_item_40_uses剩余使用次数12
  • 40并不是可选种类的上限；它代表竞技场物品栏的全部40个槽位。保存的选择没有任意的种类上限。
  • 未鉴定的物品和没有使用次数的装备无法选择。已选中但当前未持有的物品不会产生值。

最简单的角色表

<!DOCTYPE html>
<html>

  .v   { font-weight: bold; }
</style>
</head>
<body>
<table width="100%" cellspacing="0" cellpadding="6">
<tr>
  <td width="90"><img src="{{img.face}}"></td>
  <td><span class="v">{{name}}</span><br>{{race}} / {{class}}<br>{{label.level}} {{level}}</td>
</tr>
</table>
<table width="100%" cellspacing="0" cellpadding="4">
<tr><td width="50%">{{label.str}}</td><td width="50%" align="right"><span class="v">{{str}}</span></td></tr>
<tr><td>{{label.hp}}</td><td align="right"><span class="v">{{hp}}</span></td></tr>

</body>

用 {{#if}} 仅在适用时显示部分内容

<!-- 仅在分配点数期间显示 -->
{{#if bonus_pts}}<p>{{label.bonus_pts}}: {{bonus_pts}}</p>{{/if}}

<!-- 有不良状态时显示为红色 -->
<p>{{label.condition}}:
{{#if condition_bad}}<span style="color: #ff5050;">{{condition}}</span>{{else}}{{condition}}{{/if}}</p>

计量条

{{#if hp_pct}}
<table width="100%" cellspacing="0" cellpadding="0" style="border-collapse: collapse; font-size: 1px;">
<tr>
  <td width="{{hp_pct}}%" bgcolor="#4caf50" style="padding-top: 4px; padding-bottom: 4px;"></td>
  <td width="{{hp_pct_rest}}%" bgcolor="#1f3326"></td>
</tr>
</table>
{{/if}}
  • 请给两个单元格都指定宽度（只指定一个时，值为0看起来会是满的）。
  • 让单元格保持为空，并用上下内边距给它们高度。给表格设置较小的字号（font-size: 1px）可以让空单元格保持较矮。
  • 最大值为0时没有百分比，因此用 {{#if hp_pct}} 包住计量条，就可以隐藏整个计量条。

显示不正确时

现象检查事项
显示了 [key?]key的拼写（见“数值”和“标签”）
显示了“—”尚无法读取该值（例如在角色创建期间）
列表中没有该角色表文件扩展名是 .html 吗？文件在 character_sheets 文件夹中吗？添加之后点击了“重新加载”吗？

图片不显示图片文件在 character_sheets 文件夹内吗？（文件夹之外的文件不会被读取）

什么都不显示Assist已连接游戏，并且正在显示状态吗？（例如在标题画面上不会显示任何内容）

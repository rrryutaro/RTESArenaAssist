屬性介面設計（角色表）

此功能會以你選擇的設計（角色表）在「狀態」分頁中顯示狀態。請用「狀態」分頁上方的「檢視」選擇設計。「翻譯」分頁中的狀態畫面與屬性分配（建立角色與升級）也使用同一種設計。

設計是一個 HTML 檔案（範本）。你可以選用內建設計，也可以自己製作。除了屬性及其修正值，角色表還可以顯示角色的狀態、各身體部位的護甲等級，以及臉部圖像與全身圖像。

這是 Assist 的顯示功能，與遊戲本身的狀態畫面（官方手冊中稱為「角色表」）是分開的，遊戲的畫面不會改變。

切換檢視

用「狀態」分頁上方的「檢視」，選擇「標準」（之前一直使用的顯示方式）或其中一種角色表設計。你的選擇會保留到下次啟動。

  • 「翻譯」分頁中的狀態畫面與屬性分配會使用這裡選擇的檢視。「翻譯」分頁沒有自己的選擇器。
  • 數值是 Assist 從遊戲中讀取的值，與「標準」檢視相同。角色表只負責顯示，絕不會更改遊戲中的數值（透過作弊設定更改數值，請在「標準」檢視中進行）。
  • 只有在 Assist 已連線到遊戲且正在顯示狀態時，才會顯示角色表。

內建設計

內建 8 種設計，這裡依「檢視」清單的順序列出。在「檢視」中選擇其中一種，即可查看它的外觀。

設計說明
Arena 風格仿照遊戲的狀態畫面排版：修正值位於屬性列上，全身圖像位於右側
屬性卡片淺色。每項屬性一張卡片，並附上依賴該屬性的修正值（力量：傷害與最大負重，依此類推；與遊戲狀態畫面上的配對相同）。頂部是生命、疲勞與魔法點數的量表
屬性卡片（深色）採用 Assist 深色視窗配色的屬性卡片。左側是屬性；右側是各身體部位的護甲等級與全身圖像
精簡在一個較短的頁面內使用小字型，適合小視窗
儀表板深色面板。生命、疲勞、魔法點數與經驗值以量表顯示

  • 部分設計在較窄的視窗中會出現水平捲軸（屬性卡片（深色）在約 740 px 以下，Arena 風格與儀表板在約 540 px 以下）。「精簡」適合小視窗。
  • 量表的顏色與遊戲畫面中臉部圖像旁的量表一致（生命＝綠色，疲勞＝紅色，魔法點數＝藍色）。

你自己的角色表

存放位置

按下「狀態」分頁上的「開啟資料夾」，即可開啟存放你自己的角色表的資料夾。

  • 該資料夾是 character_sheets，與 RTESArenaAssist.exe 位於同一位置。
  • 第一次開啟時，Assist 會建立該資料夾，並放入內建設計的副本（不會覆蓋既有檔案）。最簡單的入門方式是編輯一份副本。
  • 資料夾中的每個 .html 檔案都會出現在「檢視」清單中。名稱是檔案的 <title> 文字（沒有則使用檔名），後面加上「（資料夾）」。修改 <title> 即可重新命名。
  • 編輯檔案後，請按下「狀態」分頁上的「重新載入」。
  • 請將檔案儲存為 UTF-8。

支援的 HTML

角色表使用 Qt 的簡易 HTML 顯示，而不是瀏覽器（不會使用網際網路連線）。

  • 支援：表格（table）、文字的顏色、大小、粗細與字型、背景色、框線（border、border-collapse）、間距（padding、margin）、圖片（img）、<style> 區塊中的類別等。詳情請參閱 Qt 文件中的「Supported HTML Subset」。
  • 不支援：指令碼、flex 與 grid、重疊（position）、圓角等。請用表格來建構版面。
  • 同一資料夾中的圖片與樣式表可以用相對路徑使用（例如 <img src="bg.png">）。資料夾之外的檔案與網際網路上的檔案不會被讀取，連結也不會被開啟。
  • 寬度為 100% 的表格，在每一欄都以 % 指定寬度時更能維持形狀。

語法

在 HTML 中寫入以下內容，該位置就會插入對應的值。

語法意義
{{key}}一個值（見「數值」）。在尚無法讀取該值時顯示「—」
{{label.key}}一個標籤（見「標籤」），以顯示語言呈現
{{img.face}} / {{img.body}}臉部圖像或全身圖像（見「圖像」）。請以 <img src="{{img.face}}"> 的形式使用
{{#if key}} … {{else}} … {{/if}}僅當 key 的值可以讀取（不為空）時顯示前半部分，否則顯示 {{else}} 之後的部分。{{else}} 可以省略。區塊可以巢狀使用。0 算作可以讀取的值
  • 未知的 key 會顯示為 [key?]，方便發現拼字錯誤（例如 {{golf}} 會變成 [golf?]）。不成對的 {{else}} 或 {{/if}} 會顯示為 [else?] 或 [/if?]，未關閉的 {{#if}} 會在文件末尾加上 [/if?]。
  • 大括號內允許有空格，例如 {{ key }}。
  • HTML 註解（<!-- … -->）內不會插入任何內容。每個內建設計頂部的註解中列出了各個 key。
  • 值會以對 HTML 安全的形式插入（值中的 < 或 & 會依原字元顯示）。

藥水數量

在遊戲的裝備清單中，為每種想要顯示的藥水勾選「角色表」欄。遊戲中已鑑定的 15 種藥水都可以選擇。治療、恢復能量與治癒疾病為初始選取項目。

Key內容範例
potion_1_name … potion_15_name以顯示語言呈現的所選藥水名稱治療藥水
potion_1_short … potion_15_short以顯示語言呈現的所選藥水簡稱（省略固定的「藥水」字樣）治療
potion_1_compact … potion_15_compact精簡卡片用的名稱（簡稱超過 14 個字元時以省略號截斷）治療
potion_1_count … potion_15_count對應藥水的持有總數4
  • 編號依藥水種類被選取的先後順序排列。未使用的欄位沒有值。
  • 內建的「屬性卡片（深色）」設計使用大型卡片，只顯示最先選取的六種。自訂的 HTML 設計可以使用全部 15 種的 key。
  • 未鑑定的藥水因種類未知而無法選擇。無法讀取物品欄時，這些值也不存在。

魔法裝備的效果與使用次數

在遊戲的裝備清單中，為每件想要顯示的魔法裝備勾選「角色表」欄。已鑑定且剩餘使用次數可讀取的物品可以選擇。同名的實體物品會分開顯示。

Key內容範例

magic_item_1_effect … magic_item_40_effect以顯示語言呈現的魔法效果名稱魔法效果
magic_item_1_uses … magic_item_40_uses剩餘使用次數12

  • 未鑑定的物品與沒有使用次數的裝備無法選擇。已選取但目前未持有的物品不會產生值。

量表

{{#if hp_pct}}
<table width="100%" cellspacing="0" cellpadding="0" style="border-collapse: collapse; font-size: 1px;">
<tr>
  <td width="{{hp_pct}}%" bgcolor="#4caf50" style="padding-top: 4px; padding-bottom: 4px;"></td>

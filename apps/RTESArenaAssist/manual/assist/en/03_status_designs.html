Status Designs (Character Sheets)

This feature shows the status on the Status tab in a design of your choice (a character sheet). Choose the design with "View" at the top of the Status tab. The status screen and the attribute distribution (character creation and level-up) on the Translate tab use the same design.

A design is an HTML file (a template). You can pick one of the bundled designs or make your own. Besides the attributes and their modifiers, a sheet can show the character's condition, the armor rating of each body part, and the face and the full-body image.

This is an Assist display feature. It is separate from the game's own status screen (called the "character sheet" in the official manual); the game's screen does not change.

Switching the view

With "View" at the top of the Status tab, choose "Standard" (the display used until now) or one of the character sheet designs. The choice is kept for the next start.

  • The status screen and the attribute distribution on the Translate tab use the view chosen here. The Translate tab has no selector of its own.
  • The values are the ones Assist reads from the game, the same as in the "Standard" view. A character sheet only displays them and never changes the game's values (changing values through the cheat settings is done in the "Standard" view).
  • A sheet is shown only while Assist is connected to the game and the status is displayed.

Your own character sheets

Where to put them

Press "Open folder" on the Status tab to open the folder for your own character sheets.

  • The folder is character_sheets, in the same place as RTESArenaAssist.exe.
  • The first time you open it, Assist creates the folder and puts copies of the bundled designs in it (existing files are not overwritten). The easiest way to start is to edit a copy.
  • Every .html file in the folder appears in the "View" list. Its name is the text of the file's <title> (or the file name if there is none) followed by "(folder)". Change the <title> to rename it.
  • After editing a file, press "Reload" on the Status tab.
  • Save the file as UTF-8.

Supported HTML

Sheets are shown with Qt's simple HTML display, not with a browser (no internet connection is used).

  • Supported: tables (table), text color, size, weight and typeface, background colors, borders (border, border-collapse), spacing (padding, margin), images (img), classes in a <style> block, and so on. See "Supported HTML Subset" in the Qt documentation for details.
  • Not supported: scripts, flex and grid, overlapping (position), rounded corners, and so on. Build the layout with tables.
  • Images and style sheets in the same folder can be used with relative paths (for example <img src="bg.png">). Files outside the folder and files on the internet are not read. Links are not opened.
  • A table of width 100% keeps its shape better when every column has a width in %.

Syntax

Write the following in the HTML, and the value is inserted in that place.

SyntaxMeaning
{{key}}A value (see "Values"). "—" while the value cannot be read yet
{{label.key}}A label (see "Labels"), in the display language
{{img.face}} / {{img.body}}The face or the full-body image (see "Images"). Use it as <img src="{{img.face}}">
{{#if key}} … {{else}} … {{/if}}Shows the first part only while the value of key can be read (is not empty), and the part after {{else}} otherwise. {{else}} can be left out. Blocks can be nested. 0 counts as a readable value
  • An unknown key is shown as [key?] so that a misspelling is easy to spot (for example {{golf}} becomes [golf?]). An unmatched {{else}} or {{/if}} is shown as [else?] or [/if?], and an unclosed {{#if}} puts [/if?] at the end of the document.
  • Spaces inside the braces are allowed, as in {{ key }}.
  • Nothing is inserted inside HTML comments (<!-- … -->). The comment at the top of each bundled design lists the keys.
  • Values are inserted in an HTML-safe form (a < or & in a value appears as that character).

Potion counts

In the game's equipment list, tick the Sheet column for each potion you want to show. All 15 identified potion types in the game can be selected. Healing, fatigue restoration and cure disease are selected initially.

KeyContentExample
potion_1_name … potion_15_nameSelected potion name in the display languagePotion of Healing

potion_1_count … potion_15_countTotal owned count for the corresponding potion4
  • The numbers follow the order in which the potion types were selected. Unused slots have no value.
  • The bundled Attribute Cards (Dark) design uses large cards and shows only the first six selected types. A custom HTML design can use the keys for all 15 types.
  • An unidentified potion cannot be selected because its type is unknown. The values are also absent while the inventory cannot be read.

Magic equipment effects and uses

In the game's equipment list, tick the Sheet column for magic equipment you want to show. Identified items with readable remaining uses can be selected. Physical items with the same name are shown separately.

KeyContentExample
magic_item_1_name … magic_item_40_nameSelected magic equipment name in the display languageItem name

magic_item_1_uses … magic_item_40_usesRemaining uses12
  • Forty is not a limit on selectable types; it represents every one of Arena's 40 inventory slots. The saved selection has no arbitrary type limit.
  • Unidentified items and equipment without uses cannot be selected. A selected item that is not currently owned produces no value.

Images

KeyContentSize
img.faceThe face (the one shown at the bottom of the game screen)80×70
img.bodyThe figure on the status screen (with the equipment worn)300×480
  • They are made from the files of your Arena (Assist does not bundle Arena's images). When they cannot be made, a transparent image of the same size is used.
  • With width / height the image is shown at that size (scaled without smoothing, keeping the coarse pixels). Whole multiples look best (for example width="160" height="140" for the face).
  • The equipment on the full-body image is checked once a second, and the image is rebuilt only when it changes.

Examples

Write the HTML characters as they are (they are shown here in a readable form).

A minimal sheet

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>My sheet</title>
<style>
  body { background-color: #1a1a2e; color: #e0e0e0;
         font-family: "Segoe UI", "Yu Gothic UI", sans-serif; }
  .v   { font-weight: bold; }
</style>
</head>
<body>
<table width="100%" cellspacing="0" cellpadding="6">
<tr>
  <td width="90"><img src="{{img.face}}"></td>
  <td><span class="v">{{name}}</span><br>{{race}} / {{class}}<br>{{label.level}} {{level}}</td>
</tr>
</table>
<table width="100%" cellspacing="0" cellpadding="4">
<tr><td width="50%">{{label.str}}</td><td width="50%" align="right"><span class="v">{{str}}</span></td></tr>
<tr><td>{{label.hp}}</td><td align="right"><span class="v">{{hp}}</span></td></tr>
</table>
</body>
</html>

Showing parts only when they apply, with {{#if}}

<!-- only while points are being distributed -->
{{#if bonus_pts}}<p>{{label.bonus_pts}}: {{bonus_pts}}</p>{{/if}}

<!-- in red when there is a bad state -->
<p>{{label.condition}}:
{{#if condition_bad}}<span style="color: #ff5050;">{{condition}}</span>{{else}}{{condition}}{{/if}}</p>

A bar

{{#if hp_pct}}
<table width="100%" cellspacing="0" cellpadding="0" style="border-collapse: collapse; font-size: 1px;">
<tr>
  <td width="{{hp_pct}}%" bgcolor="#4caf50" style="padding-top: 4px; padding-bottom: 4px;"></td>
  <td width="{{hp_pct_rest}}%" bgcolor="#1f3326"></td>
</tr>
</table>
{{/if}}
  • Give both cells a width (with only one, a value of 0 looks full).
  • Keep the cells empty and give them height with the top and bottom padding. A small font size on the table (font-size: 1px) keeps the empty cells low.
  • When the maximum is 0 there is no percentage, so wrapping the bar in {{#if hp_pct}} hides the whole bar.

When something does not show correctly

SymptomWhat to check
[key?] is shownThe spelling of the key (see "Values" and "Labels")
"—" is shownThe value cannot be read yet (for example during character creation)
The sheet is not in the listIs the file extension .html? Is the file in the character_sheets folder? Did you press "Reload" after adding it?
The layout is brokenDoes the file use something unsupported (flex, grid, and so on)? Build the layout with tables
An image does not showIs the image file inside the character_sheets folder? (files outside it are not read)
Garbled textWas the file saved as UTF-8?
Nothing is shownIs Assist connected to the game, and is the status being displayed? (nothing is shown on the title screen, for example)

상태 화면 디자인 (캐릭터 시트)

이 기능은 상태 탭의 상태를 원하는 디자인(캐릭터 시트)으로 보여줘요. 상태 탭 위쪽의 "보기"에서 디자인을 고르세요. 번역 탭의 상태 화면과 능력치 분배(캐릭터 생성과 레벨 업)도 같은 디자인을 써요.

디자인은 HTML 파일(템플릿)이에요. 기본 제공 디자인 중에서 고르거나 직접 만들 수 있어요. 시트에는 능력치와 보정 외에도 캐릭터의 상태, 부위별 방어 등급, 얼굴과 전신 이미지를 표시할 수 있어요.

이것은 Assist의 표시 기능이에요. 게임 자체의 상태 화면(공식 매뉴얼의 "캐릭터 시트")과는 별개이며, 게임의 화면은 바뀌지 않아요.

보기 전환

상태 탭 위쪽의 "보기"에서 "표준"(지금까지의 표시) 또는 캐릭터 시트 디자인 중 하나를 고르세요. 선택은 다음 실행 때도 유지돼요.

  • 번역 탭의 상태 화면과 능력치 분배는 여기서 고른 보기를 써요. 번역 탭에는 별도의 선택 항목이 없어요.
  • 값은 Assist가 게임에서 읽어 온 값이며 "표준" 보기와 같아요. 캐릭터 시트는 값을 표시만 하고 게임의 값을 바꾸지 않아요(치트 설정으로 값을 바꾸는 일은 "표준" 보기에서 해요).
  • 시트는 Assist가 게임에 연결되어 있고 상태가 표시되는 동안에만 보여요.

기본 제공 디자인

기본 제공 디자인은 8가지이며, "보기" 목록의 순서대로 나열했어요. "보기"에서 골라 모양을 확인해 보세요.

디자인설명
Arena 스타일게임의 상태 화면처럼 배치해요. 능력치 행에 보정이 붙고, 오른쪽에 전신 이미지가 있어요
능력치 카드밝은 색이에요. 능력치마다 카드가 하나씩 있고, 그 능력치에 따른 보정이 함께 나와요(힘: 피해량과 최대 중량 등, 게임의 상태 화면과 같은 짝). 위쪽에 체력, 피로, 마력 막대가 있어요
능력치 카드 (다크)능력치 카드를 Assist의 어두운 창 색으로 만든 디자인이에요. 왼쪽에 능력치, 오른쪽에 부위별 방어 등급과 전신 이미지가 있어요
컴팩트작은 창에 맞게 작은 글씨로 짧은 한 페이지에 담아요

TRPG (양피지)양피지 색과 세리프 글꼴이에요
  • 기본 제공 디자인은 1920×1080 레이아웃 모드의 상태 탭과 번역 탭에서 스크롤 없이 들어가도록 만들었어요.
  • 일부 디자인은 좁은 창에서 가로 스크롤 막대가 나타나요(능력치 카드 (다크)는 약 740 px 미만, Arena 스타일과 대시보드는 약 540 px 미만). 작은 창에는 "컴팩트"가 어울려요.
  • 막대 색은 게임 화면의 얼굴 옆 막대를 따라요(체력 = 초록, 피로 = 빨강, 마력 = 파랑).

직접 만드는 캐릭터 시트

둘 위치

상태 탭의 "폴더 열기"를 누르면 직접 만든 캐릭터 시트를 두는 폴더가 열려요.

  • 폴더는 RTESArenaAssist.exe와 같은 위치에 있는 character_sheets예요.
  • 처음 열 때 Assist가 폴더를 만들고 기본 제공 디자인의 사본을 넣어요(기존 파일은 덮어쓰지 않아요). 사본을 고쳐서 시작하는 것이 가장 쉬워요.
  • 폴더 안의 모든 .html 파일이 "보기" 목록에 나타나요. 이름은 파일의 <title> 텍스트(없으면 파일 이름) 뒤에 "(폴더)"가 붙은 형태예요. <title>을 바꾸면 이름이 바뀌어요.
  • 파일을 고친 뒤에는 상태 탭의 "다시 불러오기"를 누르세요.
  • 파일은 UTF-8로 저장하세요.

지원하는 HTML

시트는 브라우저가 아니라 Qt의 간단한 HTML 표시로 보여줘요(인터넷 연결은 쓰지 않아요).

  • 지원: 표(table), 글자 색, 크기, 굵기, 글꼴, 배경색, 테두리(border, border-collapse), 여백(padding, margin), 이미지(img), <style> 블록 안의 클래스 등. 자세한 내용은 Qt 문서의 "Supported HTML Subset"을 참고하세요.
  • 미지원: 스크립트, flex와 grid, 겹치기(position), 둥근 모서리 등. 배치는 표로 만드세요.
  • 같은 폴더에 있는 이미지와 스타일 시트는 상대 경로로 쓸 수 있어요(예: <img src="bg.png">). 폴더 밖의 파일과 인터넷의 파일은 읽지 않아요. 링크는 열리지 않아요.
  • 너비 100%인 표는 모든 열의 너비를 %로 지정하면 모양이 더 잘 유지돼요.

문법

HTML에 다음과 같이 쓰면 그 자리에 값이 들어가요.

문법의미
{{key}}값("값" 참고). 값을 아직 읽을 수 없으면 "—"
{{label.key}}레이블("레이블" 참고). 표시 언어로 들어가요
{{img.face}} / {{img.body}}얼굴 또는 전신 이미지("이미지" 참고). <img src="{{img.face}}">처럼 써요
{{#if key}} … {{else}} … {{/if}}key의 값을 읽을 수 있을 때(비어 있지 않을 때)만 앞부분을 보여주고, 그렇지 않으면 {{else}} 뒤의 부분을 보여줘요. {{else}}는 생략할 수 있어요. 블록은 중첩할 수 있어요. 0은 읽을 수 있는 값으로 취급해요
  • 알 수 없는 key는 오타를 찾기 쉽도록 [key?]로 표시돼요(예: {{golf}}는 [golf?]가 돼요). 짝이 없는 {{else}}나 {{/if}}는 [else?]나 [/if?]로 표시되고, 닫히지 않은 {{#if}}가 있으면 문서 끝에 [/if?]가 붙어요.
  • 중괄호 안의 공백은 {{ key }}처럼 써도 돼요.
  • HTML 주석(<!-- … -->) 안에는 아무것도 들어가지 않아요. 기본 제공 디자인마다 맨 위의 주석에 key 목록이 있어요.
  • 값은 HTML에 안전한 형태로 들어가요(값에 있는 <이나 &는 그 문자 그대로 나타나요).

물약 개수

게임의 장비 목록에서 시트에 표시할 물약마다 시트 열에 체크하세요. 게임에서 식별된 물약 15종을 모두 선택할 수 있어요. 처음에는 치유, 피로 회복, 질병 치료가 선택되어 있어요.

Key내용예시
potion_1_name … potion_15_name선택한 물약 이름(표시 언어)치유 물약
potion_1_short … potion_15_short선택한 물약의 짧은 이름(표시 언어, 고정된 "물약" 표현은 생략)치유
potion_1_compact … potion_15_compact컴팩트 카드용 이름(짧은 이름이 14자를 넘으면 말줄임표로 잘라요)치유
potion_1_count … potion_15_count해당 물약의 보유 총 개수4
  • 번호는 물약 종류를 선택한 순서를 따라요. 쓰지 않는 칸에는 값이 없어요.
  • 기본 제공 능력치 카드 (다크) 디자인은 큰 카드를 쓰기 때문에 선택한 종류 중 처음 6개만 보여줘요. 직접 만든 HTML 디자인에서는 15종 모두의 key를 쓸 수 있어요.
  • 식별되지 않은 물약은 종류를 알 수 없어서 선택할 수 없어요. 소지품을 읽을 수 없는 동안에도 값이 없어요.

마법 장비의 효과와 사용 횟수

게임의 장비 목록에서 시트에 표시할 마법 장비마다 시트 열에 체크하세요. 식별되었고 남은 사용 횟수를 읽을 수 있는 아이템을 선택할 수 있어요. 이름이 같은 실물 아이템은 따로 표시돼요.

Key내용예시

  • 식별되지 않은 아이템과 사용 횟수가 없는 장비는 선택할 수 없어요. 선택했지만 지금 가지고 있지 않은 아이템은 값이 없어요.

제대로 표시되지 않을 때

증상확인할 것
[key?]가 표시돼요key의 철자("값"과 "레이블" 참고)
"—"가 표시돼요값을 아직 읽을 수 없는 상태예요(예: 캐릭터 생성 중)
시트가 목록에 없어요파일 확장자가 .html인가요? 파일이 character_sheets 폴더에 있나요? 추가한 뒤 "다시 불러오기"를 눌렀나요?
배치가 깨져요지원하지 않는 것(flex, grid 등)을 쓰지 않았나요? 배치는 표로 만드세요
이미지가 나오지 않아요이미지 파일이 character_sheets 폴더 안에 있나요? (폴더 밖의 파일은 읽지 않아요)
글자가 깨져요파일을 UTF-8로 저장했나요?
아무것도 표시되지 않아요Assist가 게임에 연결되어 있고 상태가 표시되고 있나요? (예: 타이틀 화면에서는 아무것도 표시되지 않아요)

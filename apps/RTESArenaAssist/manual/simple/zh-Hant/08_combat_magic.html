戰鬥與魔法

戰鬥基礎

Arena 採用即時戰鬥。按一下滑鼠即可攻擊。能否命中以及造成多少傷害，取決於你的能力值、裝備以及敵人的護甲值（AR）。

命中率影響因素

因素效果
AGI（敏捷）攻擊方獲得命中加成；防禦方獲得防禦加成
LUC（幸運）對所有行動施加的隨機修正
紅衛人種族命中與傷害 +等級÷3（僅限近戰）

黑暗精靈種族命中與傷害 +等級÷4（近戰與遠程）

傷害

傷害 = 武器基礎值 + STR 修正 + 種族加成。目標的護甲值（AR）會減少所受的傷害——AR 越低，防護越好。

致命一擊

致命一擊 = 3 倍的一般武器傷害。
小偷系職業的角色每升一級就會增加致命一擊的機率，其中刺客的機率最高。盜賊、竊賊、吟游詩人、雜技師、武僧、弓箭手（使用弓時）與夜刃也具備這項能力。

豁免檢定

成為法術或特殊效果的目標時，豁免檢定成功可以減輕或抵銷該效果。成功機率取決於 WIL（意志力）。

職業 / 種族豁免結果
預設成功 = 傷害減半
武僧成功 = 零傷害
諾德人對寒冷豁免成功 = 零傷害
布列頓人對魔法豁免成功 = 零傷害

魔法系統

法術從你的法術書（角色表第 2 頁）中選擇。每個法術都會消耗法術點數（SP）。SP 降到 0 時，就無法施放法術。SP 由 INT 乘以各職業專屬的倍率決定。

法術點數倍率

職業SP = INT ×
法師× 2
巫術師最高 × 3（從法術中吸收，無法自行產生）
治療師× 1.75
戰鬥法師× 1.75
魔劍士× 1.5
夜刃× 1.5
吟游詩人= INT（× 1）

法術製作

可在法師公會使用。透過組合效果、範圍、持續時間與強度來創造自訂法術。治療師在防禦類效果上享有折扣；戰鬥法師在攻擊類效果上享有折扣。

經驗與升級

透過擊敗敵人與完成任務來獲得經驗。升級會提升能力值與生命（施法者還會提升 SP）。

升級時獲得的生命：擲一次職業生命骰，再加上或減去 END 的生命修正值。例如，d18 會擲出 1–18；若生命修正值為 +4，則生命增加 5–22。職業生命骰就是「角色職業」中「初始生命」底下「25 + dN」裡的「dN」。
升級速度（由快到慢）：小偷 → 戰士 → 戰士系分支職業 → 小偷系分支職業 → 法師 → 法師系分支職業

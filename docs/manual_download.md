# RTESArenaAssist — 詳細マニュアルのダウンロード / Full manual downloads

RTESArenaAssist のマニュアルタブ「詳細」で読む、公式マニュアル（Player's Guide と追補）の訳の翻訳パックです。
表示言語ごとに 1 つのファイルで、本体（`RTESArenaAssist.exe`）とは別に配っています。

## 使い方

1. 上の表から、Assist の表示言語の翻訳パックをダウンロードします。
2. Assist のマニュアルタブで「詳細」を選び、「取り込む」を押してダウンロードしたファイルを選びます。
3. 章の一覧が表示されれば完了です。取り込んだ後は、ダウンロードしたファイルを削除しても構いません。

- マニュアルの画像は、お使いの Arena（Steam 版）の `Docs` フォルダにある `Player Guide.pdf` から作ります。翻訳パックには、画像も英語の原文も入っていません。PDF が見つからない場合は文章だけを表示します。設定の「ゲームフォルダ」を確かめてから「画像を作り直す」を押すと、画像も表示されます。
- 翻訳パックが新しくなった時は、同じ手順でもう一度取り込むと置き換わります。
- Assist 自身はインターネットに接続しません。ダウンロードはお使いのブラウザで行ってください。

詳しくは [基本操作ガイド](assist_basic_guide.md#マニュアルタブ) を参照してください。

## How to use

1. Download the translation pack for your Assist display language from the table above.
2. In the Manual tab of Assist, select "Full", press "Import" and select the downloaded file.
3. When the chapter list appears, you are done. You may delete the downloaded file afterwards.

- The images are made from `Player Guide.pdf` in the `Docs` folder of your Arena (Steam version). The packs contain neither the images nor the English original text. If the PDF is not found, only the text is shown; check the "Game Folder" in the settings and press "Rebuild the images" to show the images.
- To update a pack, import the new file in the same way.
- Assist itself does not connect to the internet. Please download the packs with your browser.
- For English, the "Full" view shows links to open the official manual (PDF) in the `Docs` folder instead.
